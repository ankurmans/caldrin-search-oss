# Security policy

Report a vulnerability privately, through "Report a vulnerability" on the repository's Security tab or by email to support@caldrin.co. Do not post a security problem publicly.

In scope: the code in this repository and installations running it. Out of scope: third-party services the app calls (report those to the vendor), misconfiguration of an installation, denial of service and load testing, and `local_noauth` mode, which has no login by design and must stay on a loopback address.

Include the route, MCP tool or file, the role and workspace you used, the auth mode (`password`, `cloudflare_access` or `local_noauth`), exact steps to reproduce, and what you could read, change or spend. Use only accounts and data you own.
